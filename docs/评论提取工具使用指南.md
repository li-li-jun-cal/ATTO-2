### 2️⃣ **评论文本提取工具.py** - 增强版

**用途**: 详细提取和分析评论内容

**特点**:
- ✅ 自动解析评论结构
- ✅ 提取时间、地点、emoji 等
- ✅ 支持滑动加载更多
- ✅ 详细的 JSON 输出
- ✅ 在终端显示结果

**输出格式**:
```json
{
  "metadata": {
    "extraction_time": "2025-11-16T23:45:00",
    "total_comments": 10,
    "timestamp": "20251116_234500"
  },
  "comments": [
    {
      "index": 1,
      "timestamp": "2025-11-16T23:45:00",
```

**关键功能**:
- `extract_all_comments()` - 快速提取当前评论

- `_extract_comment_parts()` - 提取评论各部分

**使用场景**:
- 需要完整的评论分析
- 需要提取时间、地点等元数据
- 需要进行关键字匹配

### 3️⃣ **智能评论定位提取工具.py** - 高级版

**用途**: 智能定位、搜索、提取评论

**特点**:
- ✅ 关键字搜索功能
- ✅ 滑动到特定评论位置
- ✅ 智能避免重复提取
- ✅ 交互式菜单
- ✅ 增量提取

**核心方法**:
```python
# 1. 搜索评论
result = extractor.find_comment_by_text('关键字')

# 2. 滑动到特定评论
extractor.scroll_to_comment(target_index=5)

# 3. 提取单条评论
comment = extractor.extract_single_comment(1)

# 4. 提取所有评论
comments = extractor.extract_all_comments()

# 5. 滑动加载并提取
comments = extractor.extract_with_scroll(scroll_times=5)

# 6. 保存为 JSON
extractor.save_json(comments)
```

**使用场景**:
- 需要查找特定评论
- 需要快速定位到某个评论
- 需要交互式操作
- 需要避免重复提取

## 🔧 工作原理

### 评论元素结构

根据 UI 查看器信息:
```
📦 类名: android.widget.FrameLayout
🆔 ID: com.ss.android.ugc.aweme:id/e7w
📍 位置: [0,1800][1080,2088]
   宽: 1080px, 高: 288px
   中心: (540, 1944)
```

**关键点**:
- 所有评论都使用**相同的 ID** (`e7w`)
- 评论是按**索引顺序**排列的
- 每条评论是一个 FrameLayout，包含完整的文本内容
- 评论包含: 内容、用户名、时间、地点、emoji、回复按钮等

### 提取流程

```
1. 定位评论容器 (com.ss.android.ugc.aweme:id/i8_)
   ↓
2. 获取评论元素集合 (com.ss.android.ugc.aweme:id/e7w)
   ↓
3. 遍历每条评论 (索引 0, 1, 2, ...)
   ↓
4. 使用 get_text() 获取完整文本
   ↓
5. 解析文本内容（可选）
   ↓
6. 保存为 JSON
```

## ⚠️ 常见问题

### Q1: 为什么提取的评论数量不一样?

**A**:
- 快速提取只获取当前屏幕的评论
- 滑动提取会加载更多评论（需要时间）
- 评论可能在滑动过程中更新

### Q2: 如何避免提取重复的评论?

**A**:
- 智能评论定位提取工具会自动追踪已提取评论
- 它使用 `extracted_ids` 集合避免重复

### Q3: 为什么某些评论无法提取?

**A**:
- 评论可能还在加载
- 评论文本为空
- 网络问题导致元素加载失败
