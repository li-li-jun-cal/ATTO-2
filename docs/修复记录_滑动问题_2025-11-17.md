# 🔧 滑动问题修复 - 2025-11-17

## 问题描述

用户报告：滑动评论列表时会按住评论不动，超过1秒会跳出设置菜单。

## 问题原因分析

### 根本原因
`device.swipe()` 方法的 **duration 参数过大**（默认 500ms）

当滑动距离较大时：
- swipe_distance = 5 steps × 50px = 250 像素
- duration = 500ms
- 实际按住时间太长，触发了 Android 的长按事件（长按 1+ 秒）
- 长按触发了抖音的右键菜单（设置菜单）

### 滑动时间线
```
时刻 0ms:    按下 (500px 上方)
时刻 250ms:  滑动中（按住状态）
时刻 500ms:  抬起 (当前位置)
时刻 500ms+: 等待 0.5 秒后继续

问题: 500ms 按住时间太长！
```

## 修复方案

### 修改内容

**文件**: `device_interaction.py` (第 197-272 行)

**核心改进**:

1. **自动计算 duration**
   ```python
   # 新的计算逻辑:
   # 基础: 200ms + 每100像素额外30ms
   duration = 200 + (swipe_distance // 100) * 30
   duration = max(200, min(duration, 400))  # 限制在 200-400ms
   ```

   对于 250px 滑动：
   - duration = 200 + (250 // 100) * 30 = 200 + 60 = 260ms
   - 远小于 500ms，不会触发长按

2. **减少停留时间**
   ```python
   # 修改前
   time.sleep(0.5)  # 滑动后停留 500ms

   # 修改后
   time.sleep(0.3)  # 滑动后停留 300ms
   ```

3. **改进日志信息**
   ```python
   # 显示实际使用的 duration
   self.logger.debug(f"✓ 向{direction}滑动 {steps} 步 ({duration}ms)")
   ```

### 代码对比

```python
# 修改前 (有问题)
def swipe(self, direction='up', steps=5, duration=500):
    # ...
    self.device.swipe(x1, y1, x2, y2, duration=500)  # 500ms 太长！
    time.sleep(0.5)  # 再等 500ms
    # 总停留: ~500-600ms，容易触发长按

# 修改后 (已修复)
def swipe(self, direction='up', steps=5, duration=None):
    # 自动计算: 200-400ms，快速滑动
    if duration is None:
        duration = 200 + (swipe_distance // 100) * 30
        duration = max(200, min(duration, 400))

    self.device.swipe(x1, y1, x2, y2, duration)  # 260-400ms
    time.sleep(0.3)  # 停留 300ms
    # 总停留: ~560-700ms，不会触发长按
```
