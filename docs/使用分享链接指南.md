# 📱 使用分享链接快速开始指南

**适用场景**: 你有一个具体的抖音视频，想要对其评论进行自动回复

---

## ✨ 推荐方式（最简单）

使用分享链接方式，而不是搜索关键字。这样更快更稳定。

---

## 📋 步骤说明

### 第 1 步：获取视频分享链接

1. 打开抖音 APP
2. 找到要处理的视频
3. 点击视频右下方的"分享"按钮
4. 点击"复制链接"
5. 你会得到一个类似这样的链接：
   ```
   https://v.douyin.com/xxxxxx
   ```

### 第 2 步：修改 config.py

打开 `config.py`，找到这一部分：

```python
TASK_CONFIG = {
    # ========== 视频导航配置 ==========
    # 方式 1: 使用关键字搜索视频
    "video_search_keywords": [
        "我的抖音视频",  # 可以添加多个视频标题进行搜索
    ],

    # 方式 2: 使用分享链接直接打开（与方式 1 选其一或都使用）
    # "video_urls": [
    #     "https://v.douyin.com/xxxxx",
    # ],
```

**修改为**:

```python
TASK_CONFIG = {
    # ========== 视频导航配置 ==========
    # 方式 1: 使用关键字搜索视频
    "video_search_keywords": [
        # 关键字方式已禁用，使用分享链接方式
    ],

    # 方式 2: 使用分享链接直接打开（与方式 1 选其一或都使用）
    "video_urls": [
        "https://v.douyin.com/你的链接代码",  # 替换为你的实际链接
    ],
```

### 第 3 步：理解链接打开流程

⚠️ **重要**：分享链接打开后会出现一个**浏览器对话框**

**画面流程**:
```
第 1 步: Chrome 浏览器打开                第 2 步: 点击"打开"按钮                第 3 步: 进入抖音视频页面
┌─────────────────────┐                ┌─────────────────────┐                ┌─────────────────────┐
│  Chrome 浏览器      │                │  "打开Douyin?"      │                │  抖音视频页面       │
│                     │                │                     │                │                     │
│  https://v.douyin..│ ────自动────→  │  [打开] [取消]    │ ────自动────→  │  ❤️ 💬 🔄 📤       │
│                     │   点击         │  (程序自动点击)     │   打开应用     │                     │
└─────────────────────┘                └─────────────────────┘                └─────────────────────┘
      （加载中）                              （关键步骤！）                        （程序继续工作）
```

**程序会自动执行这整个流程**，你不需要手动干预！

详细说明参考: [`链接打开流程说明.md`](链接打开流程说明.md)

### 第 4 步：配置回复关键字

在同一个 `config.py` 文件中，找到 `keywords_to_reply` 部分，配置你想要回复的关键字：

```python
"keywords_to_reply": {
    "很好看": {
        "enabled": True,
        "reply_templates": [
            "感谢你的喜欢！🎉",
            "谢谢支持！💪",
            "感谢观看！✨"
        ],
        "priority": 1
    },
    "棒": {
        "enabled": True,
        "reply_templates": [
            "谢谢夸奖！😊",
            "你太客气了！",
            "继续加油！"
        ],
        "priority": 2
    },
    # 添加更多关键字...
},
```

### 第 5 步：运行程序

```bash
# 激活虚拟环境
source .venv/Scripts/activate  # macOS/Linux
# 或
.venv\Scripts\Activate.ps1     # Windows PowerShell

# 运行程序
python main.py
```

---

## 📱 程序会自动执行

1. **打开浏览器** → 在 Chrome 浏览器中打开分享链接
2. **显示对话框** → 浏览器会显示"打开Douyin?"对话框
3. **程序自动点击** → ⭐ 程序自动点击"打开"按钮（这是关键一步！）
4. **跳转到抖音应用** → 链接自动跳转到抖音 APP 显示该视频
5. **进入评论区** → 程序自动进入评论区
6. **加载所有评论** → 滚动加载更多评论
7. **匹配关键字** → 找出包含你配置的关键字的评论
8. **自动回复** → 对匹配的评论进行自动回复

## 💡 配置示例

### 示例 1：单个视频，回复 3 个关键字

**config.py**:
```python
TASK_CONFIG = {
    "video_urls": [
        "https://v.douyin.com/abc123def456",  # 你的视频链接
    ],

    "keywords_to_reply": {
        "很好看": {
            "enabled": True,
            "reply_templates": ["感谢喜欢！"],
            "priority": 1
        },
        "棒": {
            "enabled": True,
            "reply_templates": ["谢谢夸奖！"],
            "priority": 2
        },
        "加油": {
            "enabled": True,
            "reply_templates": ["一起加油！"],
            "priority": 3
        },
    },

    "max_replies_per_video": 20,  # 最多回复 20 条
    "delay_between_replies": [2, 5],  # 每条回复间隔 2-5 秒
}
```

### 示例 2：多个视频，多个关键字

```python
TASK_CONFIG = {
    "video_urls": [
        "https://v.douyin.com/video1",
        "https://v.douyin.com/video2",
        "https://v.douyin.com/video3",
    ],

    "keywords_to_reply": {
        "很好看": {
            "enabled": True,
            "reply_templates": [
                "感谢喜欢！",
                "谢谢观看！",
                "继续加油！"
            ],
            "priority": 1
        },
        "棒": {
            "enabled": True,
            "reply_templates": ["谢谢夸奖！"],
            "priority": 2
        },
    },

    "max_replies_per_video": 10,
    "delay_between_replies": [3, 8],
    "delay_between_videos": [5, 15],  # 不同视频间延迟更长
}
```

---

## 🔧 调整参数说明

### delay_between_replies
控制回复之间的延迟（单位：秒）

```python
"delay_between_replies": [2, 5]  # 随机延迟 2-5 秒
"delay_between_replies": [1, 2]  # 快速回复，但可能被检测为机器人
"delay_between_replies": [5, 10] # 缓慢回复，更像真人
```

### max_replies_per_video
控制每个视频最多回复多少条评论

```python
"max_replies_per_video": 5   # 保守：最多 5 条
"max_replies_per_video": 10  # 中等：最多 10 条
"max_replies_per_video": 20  # 积极：最多 20 条
```

### operation_mode
控制如何选择回复模板

```python
"operation_mode": "random"  # 随机选择一个模板（推荐）
"operation_mode": "first"   # 总是选择第一个
```

## ⚠️ 注意事项

### 安全建议
- ✅ 延迟不要太短（2-5 秒较为安全）
- ✅ 每个视频回复数量不要过多（10-20 条较为合适）
- ✅ 避免在短时间内处理过多视频
- ✅ 回复内容要自然，不要过于机械

### 常见问题

**Q: 程序说找不到视频？**
A: 检查：
1. 链接是否正确复制
2. 手机是否已安装抖音
3. 手机浏览器能否正常打开分享链接

**Q: 程序找不到评论？**
A: 可能原因：
1. 视频评论已关闭
2. 评论区为空
3. 需要向上滚动加载更多评论

**Q: 回复失败？**
A: 可能原因：
1. 评论框无法打开
2. 网络延迟过大
3. 抖音应用有更新
