【核心功能】
- 使用图像识别技术找到并点击谷歌浏览器中的"打开"按钮
- 支持 2 个模板文件: dakaidouyin.png 和 dakaiyouyin2.png
- 一个找到就点击，进入到抖音应用

【快速开始】

方式 1: Python 启动脚本（推荐）
  1. 打开命令行
  2. cd D:\Users\zk\Desktop\AOTO
  3. python run.py

方式 2: 自动安装依赖后运行
  1. python install_dependencies.py
  2. python main.py

方式 3: Windows 批处理文件
  1. 双击 run.bat

【依赖库】
需要安装以下库（run.py 和 install_dependencies.py 会自动安装）:
  • opencv-python >= 4.5.0
  • Pillow >= 8.0.0
  • numpy >= 1.19.0

手动安装:
  pip install opencv-python Pillow numpy

【使用流程】

1. 获取分享链接
   抖音 APP → 找到视频 → 分享 → 复制链接
   例如: https://v.douyin.com/xxxxx

2. 修改 config.py
   在 "video_urls" 列表中添加链接:
   "video_urls": ["https://v.douyin.com/你的链接"]

3. 运行程序
   推荐: python run.py
   或直接: python main.py (需先安装依赖)

4. 程序自动执行:
   • 打开谷歌浏览器
   • 加载分享链接
   • 📸 使用图像识别找到"打开"按钮
   • 自动点击按钮
   • 跳转到抖音应用
   • 自动进入视频页面
   • 自动进入评论区
   • 加载评论
   • 匹配关键字
   • 自动回复

【常见问题】

Q: 显示"图像识别库未安装"
A: 运行 python run.py 或 python install_dependencies.py

Q: 找不到按钮
A: 检查模板文件是否正确，调整匹配阈值

Q: 点击后未进入抖音
A: 检查设备连接，查看日志输出

【技术细节】

实现方式:
  - 使用 cv2.matchTemplate() 进行模板匹配
  - 选择最高匹配度的模板
  - 自动计算按钮中心坐标 (x, y)
  - 使用 device.click(x, y) 执行点击
  - 轮询等待，直到找到或超时

匹配算法: cv2.TM_CCOEFF_NORMED
超时时间: 5 秒
轮询间隔: 0.5 秒
匹配阈值: 0.7
