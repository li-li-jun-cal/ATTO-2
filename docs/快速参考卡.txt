🎯 三种使用方式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  方式 1: 最简单 (推荐)
  ─────────────────────
  python 快速启动.py
  → 一键启动，自动完成

  方式 2: 灵活选择
  ─────────────────
  python main_improved.py
  → 菜单选择，可自定义参数

  方式 3: 代码集成
  ────────────────

  workflow = ImprovedAutomationWorkflow()
  result = workflow.run()

⚙️ 参数说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  滑动次数 (scroll_times)
  ───────────────────────
  5 次  → 加载 40-50 条评论 (推荐)
  10次  → 加载 80-100 条评论 (完整)

  最多回复数 (max_replies)
  ──────────────────────
  20条  → 最安全，防封号 (推荐)
  30条  → 更多回复，风险略高
  50+条 → 不推荐

  回复间隔
  ──────
  固定 3 秒 (无需调整)

🆘 快速排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  问题: 打不开评论区
  解决: 手动打开评论区，再运行脚本

  问题: 无法定位评论
  解决: python main_improved.py → 选择完整模式

  问题: 回复失败
  解决: 系统会自动重试 (最多 3 次)，查看日志

  问题: 设备连接失败
  解决: adb kill-server && adb start-server && adb devices

🔐 安全说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  防封号保护
  ──────────
  ✅ 间隔 3 秒      (每条回复间隔)
  ✅ 最多 20 条    (每个视频)
  ✅ 智能延迟      (点击、输入、发送)
  ✅ 自动重试      (失败自动重试)
  ✅ 动态定位      (永远准确)

  使用建议
  ────────
  单个视频  → 15-20 条
  多个视频  → 间隔 10 秒
  每天总计  → 不超过 100 条
