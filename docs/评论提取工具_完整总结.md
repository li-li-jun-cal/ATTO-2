## 📋 实际使用示例

### 示例 1: 批量提取 3 个视频的评论

```python
import time
from device_interaction import DeviceInteraction
from 实时评论监听提取工具 import RealtimeCommentMonitor
from element_ids import DouyinElementIds

device = DeviceInteraction()
video_ids = ['1234567890', '1234567891', '1234567892']

for video_id in video_ids:
    print(f"\n处理视频: {video_id}")

    # 打开视频
    url = f"https://www.douyin.com/video/{video_id}"
    device.device.open(url)
    time.sleep(3)

    # 点击评论按钮
    device.device(resourceId=DouyinElementIds.COMMENT_BUTTON).click()
    time.sleep(2)

    # 提取评论
    monitor = RealtimeCommentMonitor(device)
    comments = monitor.monitor_and_extract(scroll_times=3)

    # 保存
    filename = f'comments_{video_id}.json'
    monitor.save_to_json(filename)

    print(f"✓ 已保存 {len(comments)} 条评论")

device.close()
```

### 示例 2: 自动回复特定关键字

```python
from 实时评论监听提取工具 import RealtimeCommentMonitor
from element_ids import DouyinElementIds

monitor = RealtimeCommentMonitor(device)
comments = monitor.monitor_and_extract()

for comment in comments:
    # 检查是否包含关键字
    if '点赞' in comment['text'] or '支持' in comment['text']:
        print(f"找到关键词评论: {comment['text']}")

        # 获取位置
        x = comment['position']['center_x']
        y = comment['position']['center_y']

        # 点击此评论的回复按钮
        device.click(x, y)
        time.sleep(1)

        # 输入回复文本
        device.input_text("感谢您的支持！💕")
        time.sleep(1)

        # 点击发送
        device.device(resourceId=DouyinElementIds.SEND_TEXT_COMMENT).click()
        time.sleep(2)
```

## ⚠️ 常见问题解答

### Q: 如何选择合适的工具？

**A**: 根据你的需求：
- **只是测试** → 快速提取
- **分析文本** → 详细提取
- **寻找评论** → 智能定位
- **自动化操作** → 实时监听 ⭐

### Q: 精确位置信息有什么用？

**A**: 可以用于：
- 🖱️ 精确点击回复按钮
- 📍 在截图上标注评论位置
- 📊 分析评论分布
- 🎯 自动化操作

### Q: 怎样避免提取重复评论？

**A**: 各工具的处理：
- 快速提取：不处理，可能有重复
- 详细提取：部分处理
- 智能定位：完整处理
- 实时监听：完整处理（推荐）⭐

### Q: 可以保存多少条评论？

**A**: 理论上无限制。但考虑到：
- 屏幕显示限制：通常 5-10 条可见评论
- 每次滑动加载：新增 1-3 条评论
- 推荐单次提取：20-50 条评论
- 如需更多：多次运行或增加滑动次数
