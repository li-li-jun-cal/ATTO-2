## 🎯 使用方式（最终版）

### 第 1 步：获取分享链接

```
手机抖音 APP → 找到你的视频 → 分享 → 复制链接
得到: https://v.douyin.com/xxxxx
```

### 第 2 步：配置 config.py

```python
TASK_CONFIG = {
    # 使用分享链接方式
    "video_urls": [
        "https://v.douyin.com/你的链接代码",  # 粘贴你的链接
    ],

    # 配置要回复的关键字
    "keywords_to_reply": {
        "很好看": {
            "enabled": True,
            "reply_templates": [
                "感谢喜欢！🎉",
                "谢谢支持！💪",
            ],
            "priority": 1
        },
    },

    "max_replies_per_video": 10,
    "delay_between_replies": [2, 5],
}
```

### 第 3 步：运行程序

```bash
python main.py
```

**就这么简单！完全自动化！** ✨
