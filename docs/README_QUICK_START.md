## ⚡ 3 个步骤启动

### 步骤 1：获取分享链接
```
抖音 APP → 找到视频 → 分享 → 复制链接
得到: https://v.douyin.com/xxxxx
```

### 步骤 2：修改 config.py
```python
TASK_CONFIG = {
    "video_urls": [
        "https://v.douyin.com/你的链接",  # 粘贴这里
    ],

    "keywords_to_reply": {
        "很好看": {
            "enabled": True,
            "reply_templates": ["感谢喜欢！"],
            "priority": 1
        },
    },

    "max_replies_per_video": 10,
    "delay_between_replies": [2, 5],
}
```

### 步骤 3：运行程序
```bash
python main.py
```

**就这么简单！** ✨

## 📱 程序会自动执行

```
打开谷歌浏览器 → 显示对话框 → 自动点击"打开"按钮 ⭐
    ↓
(程序自动适配不同 Chrome 版本)
    ↓
跳转到抖音应用 → 加载视频页面
    ↓
进入评论区 → 加载评论
    ↓
匹配关键字 → 自动回复
```

**完全自动，无需手动干预！** 🤖

> 💡 **支持所有谷歌浏览器版本** - 程序会自动尝试多个按钮 ID 直到找到正确的
