## 🔄 工作流程

```
START
  ↓
📱 [1] 连接设备
  ↓
🎬 [2] 进入视频页面 (如果需要)
  ↓
💬 [3] 打开评论区 ⭐ (关键!)
  │   - 点击评论按钮
  │   - 或点击评论数文本
  │   - 或检查评论容器
  ↓
📜 [4] 加载评论 (滑动加载)
  ↓
🔍 [5] 匹配关键字
  ↓
💌 [6] 自动回复 (每条 3 秒间隔)
  ├─ 动态定位评论位置
  ├─ 点击打开回复框
  ├─ 输入回复文本
  ├─ 发送回复
  └─ 失败自动重试
  ↓
📊 [7] 生成报告
  ↓
END ✅
```

**总耗时**: 约 2-3 分钟

## 🎯 参数说明

### 滑动次数 (scroll_times)
- **5 次** (默认): 加载 40-50 条评论 ⭐ 推荐
- **10 次**: 加载 80-100 条评论 (更完整)

### 最多回复数 (max_replies)
- **20 条** (默认): 最安全，防封号 ⭐ 推荐
- **30 条**: 更多回复，但风险略高
- **50+ 条**: 不推荐，容易被检测

### 回复间隔
- **固定 3 秒**: 避免操作过快被检测
- 无需手动调整

## 🔐 安全说明

### 防封号保护

```
✅ 间隔 3 秒    - 操作不过快

✅ 自动延迟    - 点击、输入、发送都有延迟
✅ 智能重试    - 失败自动重试，避免强行点击
```

```
单个视频   → 回复 15-20 条
```

## ❓ 常见问题

**Q: 安全吗？**
A: 是的。系统有完整的防封号保护，包括间隔延迟、回复数量限制、动态定位等。

**Q: 可以自定义回复文本吗？**
A: 可以。创建 `my_keywords.json` 文件，在菜单中选择自定义模式。

**Q: 支持批量多个视频吗？**
A: 支持。可以写一个简单的循环脚本，每个视频之间等待 10 秒。

**Q: 失败了怎么办？**
A: 系统会自动重试最多 3 次。详细信息保存在日志中，查看 `logs/auto_reply_*.log`。

**Q: 需要保存账号密码吗？**
A: 不需要。系统只与设备通讯，不涉及账号认证。

**Q: 可以中途取消吗？**
A: 可以。按 Ctrl+C 即可中断脚本。
