## 问题 1: swipe() 方法参数签名不匹配

**文件**: `实时评论监听提取工具.py` (第 77-83 行)

**错误信息**:
```
TypeError: DeviceInteraction.swipe() got an unexpected keyword argument 'sx'
```

**原因**:
实时评论监听工具使用了旧的 swipe 参数格式 (sx, sy, ex, ey)，但 DeviceInteraction.swipe() 实际使用的是 (direction, steps, duration)

**修复方案**:
```python
# 修改前:
self.device.swipe(
    sx=container.center()[0],
    sy=container.center()[1] + 100,
    ex=container.center()[0],
    ey=container.center()[1] - 100,
    duration=500
)

# 修改后:
self.device.swipe(direction='up', steps=5, duration=500)
```

**状态**: ✅ 已修复

## 问题 2: 设备关闭时报错

**文件**: `device_interaction.py` (第 660-673 行)

**错误信息**:
```
AttributeError: 'Device' object has no attribute 'close'
```

**原因**:
uiautomator2 的 Device 对象没有 close() 方法。close() 调用 self.device.close() 导致错误。

**修复方案**:
```python
# 修改前:
def close(self):
    try:
        if self.device:
            self.device.close()  # ❌ Device 没有 close 方法
            self.logger.info("✓ 设备连接已关闭")
    except Exception as e:
        self.logger.error(f"✗ 关闭设备连接失败: {e}")

# 修改后:
def close(self):
    try:
        if self.device:
            # uiautomator2 Device 对象没有 close 方法，直接设置为 None
            self.device = None
            self.logger.info("✓ 设备连接已关闭")
    except Exception as e:
        self.logger.error(f"✗ 关闭设备连接失败: {e}")
```

**状态**: ✅ 已修复
