## ⚙️ 参数说明

### 滑动次数 (scroll_times)
- **含义**: 加载评论时的向上滑动次数
- **推荐值**: 5-10
- **说明**:
  - 5 次 ≈ 加载 40-50 条评论
  - 10 次 ≈ 加载 80-100 条评论

### 最多回复数 (max_replies)
- **含义**: 最多回复的评论条数
- **推荐值**: 20
- **说明**:
  - 防止频繁回复导致账号异常
  - 可根据需要调整 (20-50 条较安全)

### 回复间隔 (wait_between_replies)
- **含义**: 每条回复之间的等待时间
- **固定值**: 3 秒
- **说明**: 避免操作过快被检测

## 🆘 常见问题

### Q1: 系统打不开评论区怎么办？

**可能原因**:
1. 视频页面未完全加载
2. UI 元素还未渲染
3. 需要手动点击

**解决方案**:
```
1. 等待视频完全加载
2. 手动点击一次评论区
3. 然后重新运行脚本
```

### Q2: 无法定位评论怎么办？

**可能原因**:
1. 评论已滑出屏幕
2. 网络延迟导致 UI 更新慢
3. 评论内容不一致

**解决方案**:
```python
# 增加滑动次数
python main_improved.py
# 选择完整模式 (10 滑动)
```

### Q3: 回复失败有什么办法？

**可能原因**:
1. 网络延迟
2. 设备性能不足
3. 抖音服务响应慢

**解决方案**:
```
1. 系统会自动重试 (最多 3 次)
2. 检查网络连接
3. 关闭其他应用释放资源
4. 查看日志了解详细信息: logs/auto_reply_*.log
```

### Q4: 怎样查看详细日志？

```bash
# Windows
type logs/auto_reply_*.log

# macOS/Linux
cat logs/auto_reply_*.log
```

## 🎓 工作流详解

### 步骤 1: 连接设备
系统使用 uiautomator2 库连接 Android 设备，建立通信通道。

### 步骤 2: 打开视频 (可选)
如果提供了视频链接，系统会触发打开。通常需要用户手动或通过浏览器打开。

### 步骤 3: 等待视频页面加载
系统检测点赞按钮，确认视频页面已加载。

### 步骤 4: 打开评论区 ⭐ (最关键!)
这是整个系统的关键步骤，有 3 个策略：
1. **方法 1**: 点击评论按钮 (resourceId: em=)
2. **方法 2**: 点击评论数文本 (resourceId: title, 显示 "62条评论")
3. **方法 3**: 检查评论容器是否已存在 (resourceId: i8_)

系统会依次尝试，任一成功即可。

### 步骤 5: 加载评论
向上滑动评论容器，加载更多评论。每次滑动会获取当前屏幕的评论数据。

### 步骤 6: 匹配关键字
使用 `KeywordMatcher` 对所有加载的评论进行关键字匹配，找出需要回复的评论。

### 步骤 7: 自动回复
对每条匹配的评论：
1. **动态定位**: 实时查询 UI 层级，获取最新坐标
2. **点击评论**: 点击评论内容，打开回复框
3. **输入回复**: 在输入框中输入回复文本
4. **发送回复**: 点击发送按钮
5. **自动重试**: 如果失败，自动重试最多 3 次

### 步骤 8: 生成报告
统计所有回复的结果，生成 JSON 报告保存到 `outputs/` 目录。
