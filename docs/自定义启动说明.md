# 🎯 自定义启动脚本 - 完全由用户控制

**新脚本**: `自定义启动.py`
**功能**: 用户自定义关键词、回复内容和回复数量

---

## 使用方式

```bash
python 自定义启动.py
```

---

## 交互流程

### 第一步: 选择关键词方式

```
请选择:
1. 使用默认关键词
2. 自定义关键词
3. 混合模式 (默认 + 自定义)

请选择 (1-3): _
```

**选项说明**:
- **1**: 使用系统默认的 10 个关键词
- **2**: 完全由你定义关键词和回复
- **3**: 先用默认的，再添加你自己的

---

## 选项详解

### 选项 1: 使用默认关键词

直接显示默认的 10 个关键词：

```
📋 默认关键词 (10 个):
============================================================
 1. 点赞          → 感谢点赞！🙏
 2. 支持          → 感谢支持，继续加油！💪
 3. 棒            → 感谢评价！😊
 4. 👍           → 谢谢！💕
 5. 顶            → 感谢支持！🎉
 6. 很有意思      → 哈哈，感谢喜欢！😄
 7. 非常好        → 感谢评论！✨
 8. 推荐          → 感谢推荐！🙏
 9. 赞            → 感谢点赞！
10. 加油          → 谢谢鼓励，继续加油！💪
============================================================
```

### 选项 2: 自定义关键词

你来定义所有关键词和回复：

```
🔧 自定义关键词
============================================================
请输入关键词和对应的回复文本
格式: 关键词|回复文本 (用 | 分隔)
输入空行完成

1. 请输入 (或按 Enter 完成): 点赞|谢谢！_
   ✓ 已添加: 点赞 → 谢谢！

2. 请输入 (或按 Enter 完成): 支持|继续加油！_
   ✓ 已添加: 支持 → 继续加油！

3. 请输入 (或按 Enter 完成): 棒|你真棒！_
   ✓ 已添加: 棒 → 你真棒！

4. 请输入 (或按 Enter 完成): _
   (按 Enter 完成)

✅ 共添加 3 个关键词
```

### 选项 3: 混合模式

先显示默认关键词，然后让你添加自定义的：

```
📋 默认关键词 (10 个):
============================================================
... (显示所有默认关键词)
============================================================

现在添加自定义关键词:
1. 请输入 (或按 Enter 完成): 我的关键词|我的回复_
   ✓ 已添加

✅ 共添加 1 个关键词
```

## 第二步: 配置回复数量

```
📊 回复配置
============================================================
一共匹配了多少条评论，最多回复多少条？
推荐: 15-20 条（防止被检测为机器人）

请输入最多回复数 (默认 20): 15_
```

**说明**:
- 匹配到的评论可能有很多
- 你可以选择只回复其中的一部分
- 推荐 15-20 条（防止被检测）
- 输入 0 跳过（使用默认值 20）

---

## 第三步: 配置评论加载

```
📜 评论加载配置
============================================================
要加载多少屏评论？
5 次  → 加载 40-50 条评论
10 次 → 加载 80-100 条评论
推荐: 5-10 次

请输入滑动次数 (默认 5): 5_
```

**说明**:
- 滑动次数越多，加载的评论越多
- 5 次较快，10 次较完整
- 选择根据需要调整

---

## 第四步: 确认配置

```
✅ 配置确认
============================================================

关键词数量: 3 个
最多回复数: 15 条
滑动次数: 5 次
预期加载评论: 40-50 条

关键词列表:
   1. 点赞          → 谢谢！
   2. 支持          → 继续加油！
   3. 棒            → 你真棒！

============================================================
确认以上配置？(y/n): y_
```

输入 `y` 确认，`n` 取消

## 配置文件

运行后会自动保存配置：

```

```

内容示例：

```json
{
  "keywords": {
    "点赞": "感谢点赞！",
    "支持": "继续加油！",
    "棒": "你真棒！"
  },
  "max_replies": 15,
  "scroll_times": 5
}
```

下次运行时可以重新使用这个配置。

## 常见问题

### Q: 可以定义多少个关键词？

A: 没有限制！想定义多少就多少。

### Q: 关键词可以有特殊字符吗？

A: 可以！支持中文、emoji、符号等。

### Q: 回复内容可以很长吗？

A: 可以，但建议简洁有力（40 字内最佳）。

### Q: 如果匹配不到怎么办？

A: 会显示 "未匹配到任何评论"，可以调整关键词后重试。

### Q: 可以中途停止吗？

A: 可以，按 Ctrl+C 即可中断。
