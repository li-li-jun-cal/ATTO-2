# 🔧 安装图像识别库

## 问题诊断

当运行 `python main.py` 时，出现以下警告：
```
⚠️  图像识别库未安装，跳过图像识别
```

这表示以下库之一未安装：
- `opencv-python` (cv2)
- `Pillow` (PIL)
- `numpy`

## 解决方案

### 方案 1: 一键安装（推荐）

打开命令行/终端，运行：

```bash
pip install opencv-python Pillow numpy -i https://pypi.tsinghua.edu.cn/simple
```

> 使用清华源加快下载速度

### 方案 2: 国内镜像安装

```bash
# 阿里镜像
pip install opencv-python Pillow numpy -i https://mirrors.aliyun.com/pypi/simple/

# 豆瓣镜像
pip install opencv-python Pillow numpy -i http://pypi.douban.com/simple

# 官方源
pip install opencv-python Pillow numpy
```

### 方案 3: 分别安装

```bash
pip install opencv-python
pip install Pillow
pip install numpy
```

## 验证安装

安装完成后，运行以下命令验证：

```bash
python << 'EOF'
try:
    import cv2
    print("✓ opencv-python 已安装")
except ImportError:
    print("✗ opencv-python 未安装")

try:
    from PIL import Image
    print("✓ Pillow 已安装")
except ImportError:
    print("✗ Pillow 未安装")

try:
    import numpy
    print("✓ numpy 已安装")
except ImportError:
    print("✗ numpy 未安装")

print("\n✓ 所有库已安装！可以运行 python main.py")
EOF
```

## 完整的依赖列表

如果要一次性安装所有依赖，使用 `requirements.txt`：

### 创建 requirements.txt

在 AOTO 目录下创建 `requirements.txt`，内容如下：

```
uiautomator2>=3.0.0
Pillow>=8.0.0
opencv-python>=4.5.0
numpy>=1.19.0
```

### 安装依赖

```bash
pip install -r requirements.txt
```

## 故障排查

### 1. pip 版本过旧

```bash
# 升级 pip
python -m pip install --upgrade pip
```

### 2. 网络连接问题

检查网络连接或使用国内镜像源。

### 3. Python 版本不兼容

```bash
# 查看 Python 版本
python --version

# 需要 Python 3.6+
# 如果版本过旧，请升级 Python
```

### 4. 权限问题

```bash
# Windows: 以管理员身份运行
pip install opencv-python Pillow numpy

# Linux/Mac:
pip install --user opencv-python Pillow numpy
```
