## 📋 系统架构

### 核心模块

```
一键自动回复.py (启动)
   ↓
auto_reply_controller.py (主控制器)
   ├─ keyword_matcher.py (关键字匹配) ✓
   ├─ dynamic_locator.py (动态定位) ✓ 核心！
   ├─ auto_reply_engine.py (自动回复) ✓
   └─ 实时评论监听提取工具.py (评论提取) ✓
```

### 完整工作流

```
START
  ↓
[1] 收集评论
    └─ 使用 RealtimeCommentMonitor 获取评论列表
  ↓
[2] 匹配关键字
    └─ 使用 KeywordMatcher 匹配关键字
  ↓
[3] 自动回复
    └─ 对每条匹配的评论:
       • 使用 DynamicLocator 动态定位评论 ⭐
       • 点击评论
       • 输入回复文本
       • 发送回复
  ↓
[4] 生成报告
    └─ 统计结果，生成 JSON 报告
  ↓
END (显示统计)
```

### 方式 3: 代码集成

```python
from auto_reply_controller import AutoReplyController
from device_interaction import DeviceInteraction

# 连接设备
device = DeviceInteraction()

# 创建控制器
controller = AutoReplyController(device)

# 运行完整工作流
result = controller.run_complete_workflow(
    scroll_times=5,          # 滑动次数
    max_replies=20,          # 最多回复条数
    keywords_file=None       # 关键字文件 (None = 使用默认)

if result['success']:
    print(f"成功回复: {result['stats']['successful_replies']} 条")
else:
    print(f"失败原因: {result['reason']}")

device.close()
```

## ⚙️ 参数配置

### 滑动次数 (scroll_times)

- **含义**: 加载评论时的滑动次数
- **推荐值**: 5-10
- **说明**:
  - 5 次 ≈ 加载 40-50 条评论
  - 10 次 ≈ 加载 80-100 条评论

### 最多回复数 (max_replies)

- **含义**: 最多回复的评论条数
- **推荐值**: 20
- **说明**:
  - 避免频繁回复导致被封号
  - 可以根据需要调整

### 回复间隔 (wait_between_replies)

- **含义**: 每条回复之间的等待时间
- **固定值**: 3 秒
- **说明**:
  - 避免操作过快被检测
  - 内置设置，暂不可改

### 关键字配置 (keywords_file)

- **含义**: 自定义关键字和回复文本
- **默认**: 使用内置关键字
- **使用**:
  ```python
  # 使用自定义配置
  result = controller.run_complete_workflow(
      keywords_file='my_keywords.json'
  )
  ```

## 🔍 核心特性详解

### 1. 动态定位 ⭐ (最重要)

**为什么需要?**
- 坐标会变化 (评论是动态的)
- 滑动会改变位置
- 不能依赖历史坐标

**如何工作?**
```python
# DynamicLocator 在每次操作前都会:
1. 查询最新的 UI 层级
2. 在所有评论中搜索目标
3. 获取最新的屏幕坐标
4. 返回实时位置
```

**优势**:
- ✅ 永远准确 (不依赖计算)
- ✅ 自动适应 (处理所有高度)
- ✅ 非常稳定 (不受延迟影响)

---

### 2. 自动重试

**如果第一次失败怎么办?**
- 自动重试，最多 3 次
- 每次重试会重新定位
- 智能等待和重试

**重试流程**:
```
尝试 1 失败
  ↓ (等待 2 秒)
尝试 2 失败
  ↓ (等待 2 秒)
尝试 3 成功 ✓
```

---

### 3. 防封号保护

**安全的回复间隔**:
- 每条回复之间等待 3 秒
- 避免频繁操作被检测
- 推荐每个视频最多 20 条

## 🆘 故障排除

### Q1: "评论未找到"

**可能原因**:
1. 评论已滑出屏幕
2. 网络延迟导致 UI 未更新
3. 评论内容不同

**解决方案**:
```python
# 增加滑动次数和重试次数
result = controller.run_complete_workflow(
    scroll_times=10,  # 从 5 增加到 10
    max_replies=20
)
```

### Q2: "回复框未打开"

**可能原因**:
1. 点击坐标不准确
2. 网络延迟
3. UI 元素加载慢

**解决方案**:
```python
# 系统已内置自动重试，会自动处理
# 如果仍然失败，检查:
# 1. 抖音是否正常运行
# 2. 网络连接是否稳定
# 3. 设备响应是否正常
```

### Q3: "输入失败"

**可能原因**:
1. 输入框未获得焦点
2. 文本输入有特殊字符
3. 输入框加载不完整

**解决方案**:
```python
# 简化回复文本，避免特殊字符
reply_text = "感谢评论！"  # 简洁有力
```

## 📝 常见问题 FAQ

### Q: 可以一次回复 100 条吗?

**A**: 不推荐。原因:
- 容易被检测为机器人
- 容易被账号限制
- 建议单个视频最多 20 条

### Q: 回复内容会重复吗?

**A**: 不会。每条评论都会根据其关键字回复相应的文本。

### Q: 可以自定义回复延迟吗?

**A**: 暂不支持。固定 3 秒是最佳的防封号配置。

### Q: 系统会保存账号密码吗?

**A**: 不会。系统只与设备通讯，不涉及账号。

### Q: 中途可以中断吗?

**A**: 可以，按 Ctrl+C 即可中断。
