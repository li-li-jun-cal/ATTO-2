🔧 关键代码片段:

# 快速提取
from device_interaction import DeviceInteraction
from element_ids import DouyinElementIds

device = DeviceInteraction()
comments = device.device(resourceId=DouyinElementIds.COMMENT_ITEM)
for idx in range(len(comments)):
    text = comments[idx].get_text()
    print(f"评论 {idx+1}: {text}")

# 详细提取
from 评论文本提取工具 import CommentTextExtractor
extractor = CommentTextExtractor(device)
comments = extractor.extract_all_comments()
extractor.save_to_json(comments)

# 智能提取
from 智能评论定位提取工具 import SmartCommentExtractor
extractor = SmartCommentExtractor(device)
result = extractor.find_comment_by_text('关键字')

📋 工作原理:

评论元素信息:
  📦 类名: android.widget.FrameLayout
  🆔 ID: com.ss.android.ugc.aweme:id/e7w
  📍 宽度: 1080px, 高度: 288px
  ✅ 所有评论使用同一个 ID，需要按索引遍历

获取流程:
  1. 定位评论元素 (ID: e7w)
  2. 获取总数 len(comment_elements)
  3. 循环遍历 for idx in range(count)
  4. 提取文本 item.get_text()
  5. 保存为 JSON

🐛 常见问题:

Q: 为什么提取 0 条评论?
A: 1. 评论区还未加载，等待几秒
   2. 确认已点击"评论按钮"
   3. 检查元素 ID 是否正确

Q: 提取的评论内容格式奇怪?
A: 这是正常的！评论包含:
   - 评论文本
   - 用户信息
   - 时间
   - 地点
   - emoji
   - 回复按钮
   详细提取工具会自动解析这些

Q: 如何批量提取多个视频的评论?
A: 在脚本中循环:
   for url in video_urls:
       # 打开视频
       # 点击评论
       # 提取评论
       # 保存 JSON
