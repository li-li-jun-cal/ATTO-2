## 🔑 关键概念速查

### 评论元素定位

```
资源 ID: com.ss.android.ugc.aweme:id/e7w
容器 ID: com.ss.android.ugc.aweme:id/i8_

关键点:
- 所有评论共享同一个 ID
- 需要通过索引遍历
- 每个评论包含完整文本
- 位置信息在 bounds 中
```

### 文本结构

```
典型评论文本:
"太Zh子,博主你发，天天发。百看不腻[看][看],11-05, · 澳大利亚,回复 按钮,作者回复过"

包含信息:
- 评论内容: "太Zh子,博主你发..."
- emoji: "[看][看]"
- 时间: "11-05"
- 地点: "澳大利亚"
- 回复标记: "回复 按钮"
- 作者回复: "作者回复过"
```

### 位置信息

```
bounds: [left, top, right, bottom]
示例: [0, 1800, 1080, 2088]

计算:
- width = right - left = 1080
- height = bottom - top = 288
- center_x = (left + right) / 2 = 540
- center_y = (top + bottom) / 2 = 1944
```
