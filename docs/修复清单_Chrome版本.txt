【三步快速开始】

1️⃣ 获取分享链接
   抖音 APP → 找到视频 → 分享 → 复制链接
   得到: https://v.douyin.com/xxxxx

2️⃣ 修改 config.py
   将链接粘贴到:
   "video_urls": [
       "https://v.douyin.com/你的链接",
   ]

3️⃣ 运行程序
   python main.py

   程序自动执行:
   - 打开谷歌浏览器
   - 显示"打开Douyin?"对话框
   - 自动点击"打开"按钮 ⭐
   - 跳转到抖音应用
   - 加载视频
   - 进入评论区
   - 加载评论
   - 匹配关键字
   - 自动回复
