## 🎯 使用方式（最终版）

### 第 1 步：获取分享链接

在抖音 APP 中：
1. 找到你的视频
2. 点击"分享"
3. 点击"复制链接"
4. 得到链接：`https://v.douyin.com/xxxxx`

### 第 2 步：配置 config.py

```python
TASK_CONFIG = {
    # 使用分享链接方式
    "video_urls": [
        "https://v.douyin.com/你的链接代码",  # 粘贴你的链接
    ],

    # 配置要回复的关键字
    "keywords_to_reply": {
        "很好看": {
            "enabled": True,
            "reply_templates": [
                "感谢喜欢！🎉",
                "谢谢支持！💪",
            ],
            "priority": 1
        },
        "棒": {
            "enabled": True,
            "reply_templates": ["谢谢夸奖！😊"],
            "priority": 2
        },
    },

    "max_replies_per_video": 10,  # 最多回复 10 条
    "delay_between_replies": [2, 5],  # 每条回复间隔 2-5 秒
}
```

### 第 3 步：运行程序

```bash
# 激活虚拟环境
.venv\Scripts\Activate.ps1

# 运行程序
python main.py
```
