## 📌 核心理念

> **一边滑动一边动态获取评论的定位信息和文字内容**

这个工具充分利用了 `ui_viewer.py` 的 UI 解析能力，通过以下方式实现：

1. **实时 UI 层级解析** - 使用 `device.dump_hierarchy()` 获取当前 UI XML
2. **评论元素定位** - 在 XML 中精确找到所有评论元素的位置
3. **动态去重** - 使用 bounds 作为 key 避免重复提取
4. **位置信息保存** - 记录每条评论的精确屏幕位置 (x, y, width, height)

## 🎯 实时评论监听提取工具详解

### 工作原理

```
设备状态
   ↓
dump_hierarchy() 获取 UI XML
   ↓
XML 解析找评论元素 (resource-id: e7w)
   ↓
提取每条评论的:
  - 文本内容
  - bounds (坐标)
  - 其他属性
   ↓
使用 bounds 去重 (避免重复)
   ↓
保存为 JSON + CSV
```

### 关键特性

#### 1️⃣ 精确定位 (position)

```json
{
  "position": {
    "x": 0,              // 左上角 X 坐标
    "y": 1800,           // 左上角 Y 坐标
    "width": 1080,       // 宽度
    "height": 288,       // 高度
    "center_x": 540,     // 中心 X
    "center_y": 1944     // 中心 Y
  }
}
```

#### 2️⃣ 自动去重

```python
# 使用 bounds 作为唯一 key
bounds_key = comment['bounds_str']  # "[0,1800][1080,2088]"

if bounds_key not in self.comment_cache:
    # 这是新评论
    self.comment_cache[bounds_key] = comment_data
    self.all_comments.append(comment_data)
```

#### 3️⃣ UI 层级解析

```python
# 直接从 XML 获取准确的 UI 信息
xml_str = device.device.dump_hierarchy()
root = ET.fromstring(xml_str)

# 找所有 resource-id="com.ss.android.ugc.aweme:id/e7w" 的元素
for element in root.iter():
    if element.get('resource-id') == COMMENT_ITEM:
        # 提取元素信息
        text = element.get('text', '')
        bounds = element.get('bounds', '')
        # ...
```

## ⚠️ 常见问题

### Q1: 提取到的位置信息有什么用?

**A**: 位置信息可以用于：
- 🖱️ 精确点击特定评论
- 📍 在截图上标记评论位置
- 📊 分析评论在屏幕上的分布
- 🎯 自动化操作（如点击回复按钮）

**示例**:
```python
# 点击第一条评论
comment = comments[0]
center_x = comment['position']['center_x']
center_y = comment['position']['center_y']
device.click(center_x, center_y)
```

### Q2: 为什么有些评论被标记为重复?

**A**: 系统使用 `bounds_str` (坐标字符串) 作为唯一识别符。如果两条评论的坐标完全相同，就被认为是重复的。这通常意味着：
- 滑动时，这条评论还在屏幕上（还没有滑出）
- 这是正常的，系统会自动去重

### Q3: 如何精确定位回复按钮?

**A**: 使用评论的位置信息，回复按钮通常在评论的右下角：

```python
comment = comments[0]
x = comment['position']['x'] + comment['position']['width'] - 50
y = comment['position']['y'] + comment['position']['height'] - 20
device.click(x, y)  # 点击回复按钮
```

### Q4: 可以同时提取多个视频的评论吗?

**A**: 可以！创建一个循环：

```python
for video_id in video_ids:
    # 打开视频
    # 点击评论
    # 提取评论
    # 保存数据
```
