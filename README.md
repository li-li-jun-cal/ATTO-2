# 🚀 抖音自动回复系统

**简单、高效、易用的抖音评论自动回复工具**

## ⚡ 核心功能

输入视频链接 → 打开浏览器 → 图像识别点击"打开" → 进入抖音 → 点击评论 → 获取评论 → 筛选评论 → 自动回复

## 📁 项目结构

```
AOTO/
├── main.py                    # 主程序 - 一键启动
├── src/                       # 核心模块
│   ├── device_interaction.py         # 设备交互
│   ├── auto_reply_controller.py      # 主控制器
│   ├── auto_reply_engine.py          # 回复引擎
│   ├── 实时评论监听提取工具.py         # 评论提取
│   ├── keyword_matcher.py            # 关键词匹配
│   ├── dynamic_locator.py            # 动态定位
│   └── element_ids.py                # 元素ID配置
├── outputs/                   # 输出目录 (配置、报告)
├── logs/                      # 日志目录
├── docs/                      # 完整文档 (60+ 文档文件)
├── backup_old_files/          # 备份的旧文件
└── requirements.txt           # 依赖列表

```

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备工作

- 确保 Android 设备已连接 (USB 或无线)
- 确保 USB 调试已启用
- 确保抖音应用已安装

### 3. 运行程序

```bash
python main.py
```

## 💡 使用流程

### 步骤 1: 视频链接
- 可以输入抖音视频分享链接 (完整自动化)
  - 自动打开浏览器
  - 使用图像识别点击"打开"按钮
  - 自动跳转到抖音应用
- 或直接使用已打开的视频 (跳过链接打开)

### 步骤 2: 关键词设置
选择以下模式之一：
1. **默认关键词** - 10个常用关键词
2. **自定义关键词** - 完全自定义
3. **混合模式** - 默认 + 自定义

### 步骤 3: 运行参数
- 滑动次数：加载评论的次数 (默认 5次)
- 最多回复：最多回复评论数 (默认 20条)

### 步骤 4: 确认并运行
- 检查配置
- 确认开始
- 自动运行

## 🔧 常见问题

### Q: 无法连接设备？
A: 检查 USB 连接、USB 调试是否启用，运行 `adb devices` 验证

### Q: 评论区无法打开？
A: 程序会尝试三种方法打开，如果都失败请手动打开评论区后继续

### Q: 如何自定义关键词？
A: 运行程序时选择 "自定义关键词" 或 "混合模式"，按提示输入

### Q: 如何避免被检测为机器人？
A: 默认配置已经很安全 (3秒间隔，20条限制)，不建议调整更激进
